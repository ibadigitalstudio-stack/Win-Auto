Аналітика та пікселі

Вставте лише ідентифікатори — сайт сам підключить потрібний код на всіх сторінках. Порожнє поле вимикає сервіс.

Де взяти:
  • Facebook Pixel: Events Manager → Джерела даних → ваш піксель → ID.
  • Google Analytics: Адміністратор → Потоки даних → веб-потік → Ідентифікатор вимірювання.
  • Tag Manager: ID контейнера вгорі сторінки (GTM-…). Якщо GA4 і піксель уже налаштовані всередині GTM, окремо їх тут не вказуйте, щоб події не дублювалися.
  • Search Console: Додати ресурс → Префікс URL → спосіб «Тег HTML» → скопіюйте метатег сюди, опублікуйте, зачекайте кілька хвилин і натисніть «Підтвердити» в Search Console.

Підключення до GitHub

Товари, контакти й тексти зберігаються у файлах сайту на GitHub. Щоб публікувати їх зміни, потрібен ключ доступу. Для замовлень і обліку він не потрібен.

Де взяти ключ доступу?
  1. Увійдіть на github.com і відкрийте Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. У полі Repository access оберіть «Only select repositories» і вкажіть Win-Auto.
  3. У Permissions → Repository permissions знайдіть Contents і поставте «Read and write».
  4. Натисніть Generate token, скопіюйте ключ (починається з github_pat_) і вставте його сюди.
Ключ зберігається лише у вашому браузері й надсилається тільки на GitHub. Нікому його не передавайте.
